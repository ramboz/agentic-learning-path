# Module 11 — Agent Teams and the manager-worker mental model

**Status:** Coming soon. Outline in [`_authoring/curriculum-outline.md`](https://github.com/ramboz/agentic-learning-path/blob/main/_authoring/curriculum-outline.md).

Agent Teams give Claude Code an experimental coordination layer: a lead agent breaks work down, teammate agents pick up tasks from a shared list, the lead reviews and integrates. The reframe: your job stops being "write the code" and becomes "manage the engineers writing the code." This is the explicit answer to "sub-agents are flat" from M6.

The lab runs PR Assistant as an Agent Team — lead plus three teammates — on a multi-issue PR.

This module may collapse into M10 if Agent Teams automates the worktree dance well enough by the time it lands.
