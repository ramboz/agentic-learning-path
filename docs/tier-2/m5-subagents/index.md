# Module 5 — Sub-agents, one-session orchestration, and tool scoping

**Status:** Coming soon. Outline in [`_authoring/curriculum-outline.md`](https://github.com/ramboz/agentic-learning-path/blob/main/_authoring/curriculum-outline.md).

When this module lands, it covers the move from a single Claude doing everything to a single Claude orchestrating sub-agents. Built-in sub-agents (Explore, Plan, General-Purpose), custom sub-agents written as markdown files, and the discipline of scoping tool permissions per agent rather than per session.

The lab introduces the curriculum's anchor project — PR Assistant — as three persona sub-agents (security, performance, readability) coordinated from one session.

Until then, the [`_authoring/`](https://github.com/ramboz/agentic-learning-path/tree/main/_authoring) directory has the in-progress thinking.
